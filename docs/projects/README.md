# Projects in this repository

This repository holds the protocol implementation. The other Avalon projects have their own repositories; how they
relate is described in the [ecosystem documentation](https://github.com/avalon-initiative/avalon-docs/blob/main/ecosystem/README.md).

| Project | What it is | Documentation |
|---|---|---|
| [`backend-server/`](backend-server/README.md) | The network node: `protocol` + `chain` + `indexer` + `server`, built into one binary (`avalon-server`) that runs as one combined process or as several role-specialized processes. | [`for-hosters/`](backend-server/for-hosters/README.md), [`for-maintainers/`](backend-server/for-maintainers/) |
| [`cli/`](cli/README.md) | `avalon`, the local dev and ops binary (`crates/cli`). | [`cli/README.md`](cli/README.md) |
