# For Stakeholders

Documentation written for people evaluating Avalon from the outside — whether
this is worth backing, partnering with, or building a game against — rather
than people writing code against it or contributing to it.

Nothing lives here yet beyond what's linked below. Once there's traction to
report (adoption, a working milestone-1 demo, real integration partners), this
is where a pitch-oriented summary, roadmap status, and risk assessment belong.

Until then, start with:

- [`../WhyAvalon.md`](../WhyAvalon.md) — the case for why this needs to exist,
  and why it hasn't been built yet despite the idea not being new
- [`../Proposal.md`](../Proposal.md) — the full design, phased roadmap, guiding
  principles, and an honest list of major risks (§31) and open questions (§32)
